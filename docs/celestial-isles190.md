# V19.0 Celestial Isles

Three floating islands at height 28, two bridges and deterministic shared walk height for player, pet and remote players. Sky region occupies reserved northern X/Z coordinates, not a vertically stacked second multiplayer layer. Map portal to sky and return to ground; requires 3D, public world, no mount or jump. Palace exterior, garden islands, decorative falls and batched clouds. Edge blocking instead of falling physics. No flight or interior. All 11 atlas regions declared open. Browser and real phone tests still required.
