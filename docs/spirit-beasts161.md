Local equipped pets and gallery use the new GLB loader. Deer uses node rig; cat, fox, rabbit use skinned skeletons. Approved V16.0 dragon remains unchanged. Remote and wildlife pets retain lightweight models. On-demand downloads capped at 8 MiB per model; previously loaded source GLBs remain cached in session. Test real rendering and FPS before accepting. No paid assets.
