Original asset: https://vinish-models.pages.dev/dragons/ice-dragon.glb. Modified in Wish World: jade material tint, roughness/metalness limits, normalization, orientation, animation transitions. Source states 65,600 triangles, 2.9 MB, +Z forward, Idle/Walk/Fly/Roar/Attack clips. Not an original commissioned sculpt. Same-origin allowlisted cache validates embedded rig/normal textures and clips; no asset bytes committed. Old mesh is fallback only; UI reports failures.
