# V16.2 Living World

Playable area 240 × 272, expanded from 144 × 176. Preserves coordinate mapping and original centre. 64 terrain tiles with equal edge vertex spacing and sampled normals; distance culling. Eight additional frontier waypoints, two extra bridges, full-width river, extra batched trees and grass, procedural terrain hills/trail coloration. Photo diffuse textures by Poly Haven, CC0: https://polyhaven.com/a/leafy_grass, https://polyhaven.com/a/medieval_blocks_05, https://polyhaven.com/a/medieval_wood. Same-origin 1K JPEG cache with original procedural material fallback. All V16.1 companion code preserved. Server presence bounds updated. New areas are walking/exploration terrain, not new quest towns. Browser/phone visuals and actual FPS must be verified; photo assets may fall back if unavailable.
