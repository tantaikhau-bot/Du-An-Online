# V35.2.4 — Unique Character Models

Expose an opt-in original procedural skinned character roster at /play?avatar=original; standard VRM stays default. Each of twenty character IDs generates its own mesh and skeleton, with face morphology, garment and hair profiles, and articulated fingers. Original mode currently applies to local avatar and character studio, not other players. Shared procedural builder, not 20 hand-sculpted premium models. Actual visual and animation quality requires browser testing. No changes to damage, saves or graphics quality policy.
