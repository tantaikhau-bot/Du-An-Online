Base: V35.2.8, m1, Sakurada_Fumiriya VRM sample. This branch is not a production release. Current change: softer skin/hair/fabric cel shading and outline, bounded surface roughness. No change to source mesh, bone transforms, maps, textures, facial blendshapes, animation, or any other roster entry. Run node test_traveler_appearance.cjs.

## V2 — reversible geometry study
A bounded rest-space width field widens the lower jaw and upper torso slightly, narrows the crown and waist, leaves height and depth unchanged, and transforms relative and absolute position morph targets. Only m1 on the original male source uses cloned geometry; switching presets or releasing restores the source. Original normals and tangents remain authored; visual shading and expression alignment must be checked in a browser. 1,000 numerical sample points checked for symmetry, bounds and unchanged vertical/depth positions. Three.js geometry regression is provided but not yet executed. This is a derivative sculpt, not a new standalone character asset. No production deployment.

## V3 — swept hair study
Hair-only meshes (every assigned material classified as hair) receive an asymmetric crown sweep, slightly raised crown and restrained temple width adjustment after the common V2 sculpt. The additional field is zero below the root band and leaves depth unchanged. Original textures, rig, skin weights, and authored normal/tangent data are preserved. Mixed or unidentified meshes are excluded. m1 hair spring gravity response is separately bounded; other avatars and non-hair springs retain their previous values. JavaScript parsed and 4,080 numeric/scope assertions passed in isolated evaluation; the full Three.js regression and browser visual validation remain pending. No newly authored standalone hairstyle asset; no production deployment.

## V4 — layered travel outfit
m1 receives a new curved shoulder mantle mesh with animated hem, two curved leather lapels with piping, elliptical leather belt and buckle, and a thick travel pouch with separate flap and clasp. These replace the previous m1 emblem and flat satchel, not the original VRM base clothes. Existing rig and garment geometry remain intact; attachments use chest and hip bones and existing throttled cloth deformation. Materials and geometry are released by the shared identity cleanup path. JavaScript syntax and 10,086 numerical surface assertions checked. Full Three.js integration test is provided but not executed here. Actual fit, clipping, draw-call cost and mobile rendering remain unverified. No standalone replacement garment asset or production deployment yet.

## V5 — Traveler sword and scabbard
Dedicated procedural steel sword with tapered octagonal blade, contrasting bevels, bronze guard/pommel and instanced grip rings; matching tapered leather sheath with throat liner and metal fittings. Uses existing sword parent, grip axis, 0.98 blade extent and existing draw/stow path. Variant is enabled only for m1 sword and survives late generic arsenal GLB swaps; original visibility restored for other characters. 119 isolated assertions for scope, face orientation and visibility switching passed. Full Three.js test and real browser hand/sheath alignment remain unverified. No production deploy.

## V6 — dedicated sword choreography
Five separately authored normalized arm tracks (diagonal, reverse, thrust, overhead and sweep) use the existing smooth key interpolation and impact timing. m1 sword only receives bounded grounded stance, alternating knee load, pelvis/chest follow-through and wider minimum hip abduction; air leg targets remain unchanged. Root displacement, combat damage, input, existing draw and stow, and other characters remain unchanged. 1,515 sampled poses at three impact timings, 10,605 numeric and isolation checks passed in isolated evaluation. Full Three.js regression, live skeletal contact, animation appearance and FPS remain unverified; no production deploy.
