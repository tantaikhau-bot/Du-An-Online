# WISH WORLD V6.5 — Immersive World

- New optional social destinations: dance plaza, picnic garden and flower photo gate, placed only on clear walkable, relatively flat terrain; destinations can be skipped if no suitable location is found. Routes and minimap show available spots without altering quest progress.
- Daytime butterflies, evening fireflies, nearby canopy sway and instanced flower wind, with quality-dependent limits. Water shading and sky lighting refined. These effects are procedural.
- Unified public release labels in game header, footer, welcome screen, HUD, graphics diagnostics, photo watermark, atelier, landing page and server /api/version. Click the in-game version or Settings to verify the actual server build.
- 15 inline JavaScript scripts parsed; browser rendering, shader compilation, placement, frame rate and multiplayer still need live testing.
