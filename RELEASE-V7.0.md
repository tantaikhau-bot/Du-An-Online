# WISH WORLD V7.0 — Next Generation

- Friends in the shared outdoor world can send invitations to six existing landmarks. Recipient accepts/declines, sender can cancel, expiration 120 seconds, rate limit 3/minute. Accepted invitations offer local route guidance; no forced teleport, automatic following or reward. Blocking and friendship checked server-side.
- Synchronizes selected pet species via presence, with cloned procedural models and local follow animation for remote players. Five supported species. Pet ownership remains local, exact pet coordinates and mounted horses are not synchronized.
- Version labels and /api/version updated. 15 inline JS scripts parsed; added backend tests, not executed. Browser and load testing pending. Existing HTTP presence retained.
